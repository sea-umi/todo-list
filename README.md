# Focus Todo

課題用に作成した、ブラウザ保存対応のTODOリストです。

## できること

- タスクの追加
- チェックボックスによる完了・未完了の切り替え
- タスクの削除
- すべて・未完了・完了済みでの表示切り替え
- `localStorage` を使った、ブラウザを閉じた後も残る自動保存

## 課題3で追加した機能

- **期限日設定**：締切を忘れがちな人のために、期限日を設定し、期限切れ・今日が期限を表示する。
- **優先度設定**：何から着手すべきか迷う人のために、高・中・低の優先度を設定し、高い順に表示する。
- **タスク編集**：入力ミスや内容変更をしたい人のために、作成済みタスクの名前・期限・優先度を修正できる。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 公開方法

1. GitHubで新しいリポジトリを作成する
2. このフォルダでGitの初期化・コミット・GitHubへのpushを行う
3. VercelへGitHubリポジトリを接続してデプロイする
